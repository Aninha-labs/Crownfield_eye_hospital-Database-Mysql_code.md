## ✅ Assessment Checklist
 
The guide asks each student to **independently create, execute and explain at least six purposeful SQL queries** that together include the items below.
 
| Requirement from the assessment guide | Status | Query |
|----------------------------------------|--------|-------|
| An aggregate query using `GROUP BY` and an appropriate filter such as `HAVING` | ✅ | Query 1 |
| An `INNER JOIN` across at least three related tables | ✅ | Query 2 (five tables) |
| A `LEFT JOIN` that reveals missing or optional related data | ✅ | Query 3 |
| A subquery, common table expression or `UNION`-based query | ✅ | Query 4 (CTE + subquery) |
| A stored procedure with an input parameter | ✅ | Query 5 |
| A trigger that enforces or records a meaningful business rule | ✅ | Query 6 |
